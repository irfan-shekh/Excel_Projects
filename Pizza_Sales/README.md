# 🍕 Pizza Sales Analysis

A data analytics project focused on analyzing pizza sales data using **SQL and Microsoft Excel** to uncover sales trends, customer preferences, product performance, and key business insights.

## 📌 Project Overview

This project demonstrates an end-to-end data analysis workflow:

**Raw Data → Data Cleaning → SQL Analysis → Excel Analysis → Dashboard/Insights**

The project uses a pizza sales dataset and combines SQL querying with Excel-based analysis to transform raw sales data into meaningful business insights.

## 🎯 Objectives

- Analyze overall pizza sales performance
- Identify sales trends and patterns
- Understand customer ordering behavior
- Analyze pizza categories and product performance
- Identify top-performing pizzas
- Calculate important sales KPIs
- Generate actionable business insights
